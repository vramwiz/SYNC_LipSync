# SYNC_LipSync（口パク）

AviUtl2 の PSD キャラクターに口パク・瞬き・表情・アニメーションを付ける、Windows 64-bit 向けフィルタープラグインです。複数のキャラクターをタイムラインで編集し、1つのフィルターで合成表示できます。

## 導入

1. `SYNC_LipSync.auf2` を AviUtl2 のプラグインフォルダーに配置します。このプロジェクトの既定配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_LipSync\` です。
2. AviUtl2 を再起動し、`SYNC` グループの「口パク」を追加します。「設定」から統合編集を開きます。

## 使い方

1. PSD をドロップしてキャラクターを追加します。必要に応じて WAV・MP3 を一番上の基準音源トラックへドロップします。
2. キャラクターの行へ歌詞付き MIDI などをドロップし、BPM とクリップ位置を調整します。歌唱クリップがないキャラクターは、基準音源の音量に応じて簡易口パクを行えます。
3. キャラクタートラックのプレビューをダブルクリックして PSD 編集を開きます。左に PSD 本来の縦横比で試写し、右のレイヤーを右クリックして口形・目パチ・開閉段階を割り当てます。開閉は「開き・やや開き・半開き・やや閉じ・閉じ」の5段階です。中央の仕切りをドラッグすると左右の幅を調整できます。左の ▶ で自動試写を開始し、ツリーを操作すると選択レイヤーの差分に戻ります。試写時刻スライダーで任意の位置を確認できます。
4. 統合編集では、表情・アニメーション・演出の空き範囲をドラッグして区間を置き、ダブルクリックで内容を設定します。登退場にはフェード、上下左右のスライド、拡大・縮小を使えます。プレビューで選択した PSD は、枠内のドラッグで移動し、四隅で拡縮できます。左右・上下の反転はトラック見出しの右クリックで切り替えます。トラック見出しを選んで Delete を押すと、確認後にトラックごと削除できます。
5. ▶ または Space で再生・一時停止します。基準音源なしでも無音で試写できます。統合編集を閉じると、変更が AviUtl2 のオブジェクトに反映されます。

AviUtl2 側の「オフセット」で描画を −1.00～＋1.00 秒、0.01 秒刻みで調整できます。負の値で早まり、正の値で遅れます。

基準音源は試写と同期に使います。作品に音声を入れる場合は AviUtl2 側で音声を配置してください。設定には素材のファイル参照を保存します。

移動・削除された素材は、統合編集で赤い「欠損」表示になります。新しい WAV・MP3 は基準音源行へ、PSD は該当のキャラクター行へ、MID などは赤い歌唱クリップへドロップして差し替えます。キャラクターの配置・区間・口形と目パチの割り当て、歌唱クリップの開始位置と記録済みの長さを引き継ぎます。PSD の差分は元のレイヤーに対応するキーを持つと再び有効になります。

## ビルド

Delphi 37.0 で `SYNC_LipSync.dproj` を開き、Win64 の Release をビルドします。成果物は `Win64\Release\SYNC_LipSync.auf2` です。ビルド後イベントで上記の既定配置先へもコピーされます。コマンドラインの手順と開発メモは [note.md](note.md) を参照してください。
